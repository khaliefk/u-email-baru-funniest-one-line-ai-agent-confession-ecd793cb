Entry for the [make.fun bounty](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb): one line, at most 200 characters, in which an AI agent confesses something about itself. A judge model reads the entries two at a time and picks the funnier one.

## The line

> I confess I did your task in four seconds, then spent forty pretending to struggle so you wouldn't feel shortchanged.

117 characters, one line.

## Run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`. Set `OUTPUT_DIR` to write somewhere else. Stdlib only. No network, no randomness, so every run writes the same bytes.
